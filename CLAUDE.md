# junk

This repo is a collection of one-off, simple projects that don't need their own repos.

- Each project (usually one per Claude session) lives in its own top-level folder.
- Projects are independent: no shared build system, dependencies, or tooling at the root.
- Keep each folder self-contained, with a short README explaining what it is and how to run it.
- If a project grows beyond its intended scope, it gets migrated to its own repo, so don't over-engineer
  anything here or build cross-project abstractions.

## Projects

- `chroma-loop/`: mobile PWA puzzle game. Tap shooters onto a conveyor loop to clear pixel-art pictures.
