How to play

  • Tap a shooter at the front of a column to send it onto the conveyor.
  • As it rides around the picture, it fires at the first pixel in each row or column it passes, but only if that pixel is its color.
  • The number is its ammo. It pops when it runs out.
  • If it gets back to the start with ammo left, it parks in a holding slot. Tap it to send it around again.
  • Only 5 shooters fit on the belt at once. If all 5 slots fill up, you're stuck!
  • Clear every pixel to win. Use fewer slots to earn more stars.
